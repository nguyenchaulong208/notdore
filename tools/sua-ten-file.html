# Tên gốc Tên mới Kích thước Xóa

Hướng dẫn chi tiết

Đổi tên một file thì ai cũng biết. Nhưng khi bạn phải đổi tên cả trăm file theo một cấu trúc chung, việc làm thủ công từng file trên máy tính sẽ tốn rất nhiều thời gian và dễ sai sót. Đây là lúc công cụ sửa tên hàng loạt phát huy tác dụng.

Tại sao cần đặt tên chuẩn

Tên file không chỉ để nhận diện. Một cấu trúc tên thống nhất giúp bạn sắp xếp, tìm kiếm và chia sẻ file nhanh hơn rất nhiều. Ví dụ, thay vì đặt tên scan001.jpg, scan002.jpg, một cấu trúc có ngày tháng và mã hợp đồng sẽ cho biết ngay nội dung và thời điểm của file.

Nguyên tắc chung: tên nên ngắn gọn, mô tả được nội dung, chứa mốc thời gian hoặc mã định danh, và tránh các ký tự đặc biệt không an toàn.

Cách dùng công cụ trên NotDore

  1. Mở trang Sửa tên file hàng loạt.
  2. Kéo thả hoặc chọn nhiều file cùng lúc.
  3. Nhận diện các file trong danh sách hiển thị.
  4. Áp dụng cấu trúc đặt tên: thêm tiền tố, hậu tố, đánh số thứ tự hoặc tự sửa từng tên.
  5. Xem trước kết quả, sau đó tải về dưới dạng file nén.

Một số tình huống thực tế

  • Tài liệu dự án: đặt tên theo mã dự án kèm ngày, ví dụ DA2026-001-20261105.
  • Ảnh chụp hồ sơ: thêm tiền tố hợp đồng hoặc mã hồ sơ để tra cứu nhanh.
  • Chuẩn hóa tên nhân viên: viết hoa đầu mỗi từ, xóa khoảng trắng thừa.
  • Đổi hàng loạt phần mở rộng hoặc ký tự: tìm và thay thế nhanh trong toàn bộ tên.

Câu hỏi thường gặp

File có bị thay đổi trên máy không?
Không. Công cụ chỉ thay đổi bản sao tên trong bộ nhớ trình duyệt. File gốc trên máy bạn vẫn giữ nguyên cho đến khi bạn tải về và tự thay thế.

Có giới hạn số lượng file không?
Công cụ xử lý theo lô, bạn có thể chọn nhiều file cùng lúc tùy theo dung lượng bộ nhớ trình duyệt.

Quên mất tên cũ thì sao?
Bạn có thể hoàn tác lại trước khi tải về, vì danh sách tên gốc vẫn được giữ trong bộ nhớ.

Lưu ý: trước khi tải về, hãy kiểm tra lại danh sách tên đã đổi để đảm bảo không nhầm lẫn giữa các file.
