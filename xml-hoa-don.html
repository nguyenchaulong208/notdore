Hướng dẫn sử dụng

1
Tải file XML hóa đơn điện tử từ cổng thuế hoặc phần mềm phát hành về máy.
2
Kéo thả tất cả file .xml vào ô trên (có thể chọn nhiều file cùng lúc bằng Ctrl+Click).
3
Nhấn Chọn cột hiển thị nếu muốn bật thêm các cột thông tin bổ sung (ẩn mặc định).
4
Nhấn Tải xuống Excel — file tong_hop_hoa_don.xlsx chỉ chứa các cột đang được chọn.
